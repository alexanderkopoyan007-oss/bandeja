# BANDEJA

A realistic, fluid 3D padel game for the browser. Free and open source; runs entirely client-side.

**Play:** https://alexanderkopoyan007-oss.github.io/bandeja/

```bash
npm install
npm run dev        # http://localhost:5190
npm test           # physics, rules and scoring tests
npm run typecheck  # app + pure-sim configs
```

URL options: `?court=standard|panoramic|singles-narrow`, `?backend=webgl`.

See `CLAUDE.md` for architecture, budgets and licensing rules, and `CREDITS.md` for third-party work.
